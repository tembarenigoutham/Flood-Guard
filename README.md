# 🌊 Flood Guard – Flood Risk Monitoring & Early Warning System

🚀 **Developed for Hackathon Project**  
🌱 **Domain:** Sustainability & Disaster Management  

Flood Guard is a smart disaster management web application designed to monitor flood risks, provide early warnings, and support authorities and citizens in responding effectively during flood situations in vulnerable regions like Bihar and Assam.

---

## 🌐 Live Demo

👉 https://vishwateja-123.github.io/floodguard/

---

## 🧠 Problem Statement

Flood-prone regions face:

- Delayed flood warnings ⏳  
- Manual monitoring systems 📉  
- Poor communication between authorities and citizens 📢  
- Inefficient rescue coordination 🚨  

This results in severe damage to lives, property, and infrastructure every year.

---

## 🎯 Objective

To build a system that:

- Tracks river water levels 🌊  
- Monitors rainfall data 🌧  
- Predicts flood risk levels 📊  
- Sends early alerts ⚠  
- Supports emergency response teams 🤝  

---

## 🚀 Features

### 🌊 Monitoring System
- River water level tracking  
- Rainfall monitoring  
- Flood risk prediction  
- High-risk area detection  

### 🚨 Alert System
- Flood risk alerts  
- Early warning notifications  
- Emergency support information  

### 👥 Multi-User Modules
- Citizen Dashboard  
- Officer Dashboard  
- Emergency Worker Module  

### 📊 Reports & Management
- Flood prediction reports  
- Historical flood data  
- Disaster response logs  
- Shelter & evacuation support

## 🛠 Tech Stack

- **Backend:** Python (Flask)  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** JSON / Local Storage  
- **Deployment:** GitHub Pages
