## 📌 Overview
FloodGuard is a smart flood risk monitoring and early warning system designed for flood-prone regions like Bihar and Assam.  
It collects river water levels and rainfall data, analyzes flood risk using a risk calculation engine, and provides early alerts to help authorities and citizens take preventive action.
